# BellAI Voice Training

This folder has everything for BellAi's voice. About an hour of recordings of reading scripts was used to train two text-to-speech models: GPT-SoVITS, which is fast and is the one we're using, and Orpheus 3B, which is slower but more expressive. To use the GPT-SoVITS voice, unzip GPT-SoVITS into the `GPT-SoVITS` folder and double-click `BellAi Studio.bat`. It opens a page at http://localhost:9890 where you can type something and hear it, or retrain the voice. The Orpheus scripts are in the `orpheus` folder (with Ollama installed, run `prepare_dataset.py`, `tune_voice.py`, `export_voice.py` and then `fast_speak.py`). The recordings and trained models aren't in the repo since they're too big.
