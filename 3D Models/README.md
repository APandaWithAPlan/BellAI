# BellAi 3D Models

## Overview

**BellAi 3D Models** are the printed parts for the home dashboard: a kickstand that holds the dashboard's LCD screen upright, and a small case for the microphone that listens for "BellAi". Both carry the BellAi paw print.

## Features

* Three-piece kickstand (base, front arm and rear support) that hooks together.
* Paw print cutout on the kickstand's front arm and on the top of the microphone case.
* Microphone case with openings in the side for the cable and a separate cover plate.

## Getting Started

### Prerequisites

* A 3D printer with a bed of at least 240 x 190 mm. The kickstand parts are 238 mm wide.
* A slicer that opens `.3mf` files (Bambu Studio, OrcaSlicer, PrusaSlicer or Cura).
* Files (all sizes in millimeters):

| File | Part | Size |
| --- | --- | --- |
| `Stand bottom 1.3mf` | Kickstand base, with the slots the arms sit in | 238 x 185 x 16 |
| `paw arm 1.3mf` | Kickstand front arm, with the paw print cutout and hooks at the top | 238 x 178 x 11 |
| `support arm 1.3mf` | Kickstand rear support, slatted, with pegs at the top | 238 x 171 x 28 |
| `mic box 1.3mf` | Microphone case and its cover plate | 43 x 43 x 58 |

### How to Enable / Access

1. Open a `.3mf` file in the slicer. Each kickstand file holds one part; `mic box 1.3mf` holds the case and its cover plate.
2. Lay each part on its largest flat face.
3. Slice and print.

## How to Use It

1. **Build the kickstand:** Set the bottom of the paw arm and the support arm into the slots of the stand bottom, then clip the hooks at the top of the paw arm over the pegs on the support arm.
2. **Place the screen:** Rest the dashboard's LCD on the stand.
3. **Case the microphone:** Put the microphone in the mic box, run its cable out through the side opening and fit the cover plate.
