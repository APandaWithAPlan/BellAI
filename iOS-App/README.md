# BellAI iOS App

Personal AI assistant for iOS with chat, voice, meal logging, and Apple Health integration.

## Installation

Requires Xcode and iOS 17.0 or later. Set up the [Mac server](../macserver/README.md), then open the project in Xcode:

```sh
cd iOS-App
open BellAI.xcodeproj
```

Select your signing team and a compatible device or simulator, then build and run. See [configuration](Config/README.md) for setup details.
